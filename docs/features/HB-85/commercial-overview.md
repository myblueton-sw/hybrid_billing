# Active composition

The compact title and review cluster retains visible screen ID, 12-character revision, review state and confirmation control. Related work remains available. Tabs preserve IA. Scope uses inline desktop controls; chart currency moves into the chart header and does not imply currency conversion. A single provenance line retains synthetic snapshot and connection/tax/FX basis; a disclosure holds the longer financial/state explanation. Example data configuration remains an explicit development disclosure.

The amount strip distinguishes currency-separated source costs, unavailable customer sales, unavailable organizational allocation and unknown receivables. Missing integrations use short labels rather than oversized empty cards. Cost record coverage is a source-by-organization denominator, not closing completion.

Next work and the six-month source-cost trend share the desktop band. The work list combines blocked whole closing units, missing cost records, unknown ERP results and approval-pending units, each with target/path, stage and a real fixture-inspection action. Rows are bounded at six. The presentation order is a readability choice, not deadline-based business priority. Categories overlap and are not added as unique affected targets. Actions do not approve or resolve anything. Accessible names include category, organization, source/internal-or-external path and stage.

The chart shows exact known/partial/unknown/no-data meaning, currency selection, scale references and its table equivalent. Selected detail appears directly below the work/trend band with focus transfer and return. Independent nine-stage lifecycle remains a bounded full-width table; source and organizational compositions follow. Compact layouts render work, then amount summaries, then trend in the DOM, with complete money strings and stacked composition rows.

# Type, visual rules and shared impact

Use actual local IBM Plex Sans, Sans KR and Sans Arabic at 400/600. U01 selects its locale family explicitly and disables synthetic font weights. The previously missing KR/AR 600 faces are now available throughout the bundled console; other screens using those weights may render differently. Their native-language/visual acceptance is not implied. Global revision hashing preserves prior local review evidence and prevents carrying old FIX to changed scope.

U01 uses 24px page titles, 20px section headings, 16px body/table/control text, 14px metadata and 28px key amounts. Neutral separators and subtle surfaces organize the full available width. No new max-width page, colored border, radius, gradient or shadow. Existing focus indication is preserved.
