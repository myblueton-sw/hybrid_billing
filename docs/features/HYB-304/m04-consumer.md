Own account, credential and global uncollected query state independently. Each result is tagged with immutable client/session/query/target identity; current provider authority and layout-owned request tokens fence late callbacks and page data synchronously. A changed query hides old rows/count/actions until its matching read completes. Clear old request tokens in layout cleanup, not only passive unsubscribe; keep render construction side-effect free. Current loading/error/denied/unavailable/known empty/scan-limited empty remain distinct. An empty page with next is not complete empty. Counts remain canonical decimal strings; display exact/lower_bound independently of page length and exact workspace admission. Use BigInt for counts/limits, Number only for actually safe bounded settings. Display reference_at and observed_at without treating them as current authority.

Table row highlight is limited to the loaded page. A pinned canonical detail target is separate and explicitly labelled when outside the page/filter; it remains an intentional target, not an implied member of filtered results. Resolve it by known-ID API even if no page contains it. Session/workspace/client change invalidates both. Actions use that visible canonical target and current server affordances, never a first-row/current-selection fallback.
