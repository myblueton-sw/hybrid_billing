# Review arithmetic and storage

The explicit `unit-price-source-precision-review-v1` profile follows quantity → entered unit price → review discount → additional fee. Scale 18 integer coefficients, strict finite decimal inputs, positive denominator, 0..100 discount and per-stage magnitude bounds are mandatory. Division records signed numerator/denominator/quotient/remainder and discloses any toward-zero truncation; raw remainder is not money. Signed quantity, zero, fee-driven sign change and target-minus-candidate delta remain separate and bounded. Tax/FX/tier/allowance/minimum/maximum/inheritance/commitment/margin activation remains unavailable.

Only user-entered draft parameters and row/context hashes are saved in this browser exercise. Entered prices/fees/targets are intentionally retained, but copied source quantities/prices/costs, account IDs/raw rows/search and credentials are excluded. Fresh validated authorization and row-aware generation/key checks precede hashing/restore. Policy changes invalidate candidate/adjustment; adjustment edits invalidate adjustment; source/scope/page/row changes and failures clear candidate, adjustment and immutable session baseline. No offline fallback or server financial action.
