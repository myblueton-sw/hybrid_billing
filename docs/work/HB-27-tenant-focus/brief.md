## Actual path and boundary

Add `modules/focus_import/`, `tools/focus_data.py`, `migrations/focus_import/`, version mapping under `packages/contracts/focus_import/`, validated tenant-property provisioning, focused tests, runbook and verification. Preserve existing hb_local tables, code and 49-case suite. New isolated `hb_focus` PG/CH namespaces and private original bucket reuse existing local verification services/drivers. This is a trusted local operator CLI, not deployed API/authentication; selected local actors have distinct DB roles. No real customer/CSP account access, automatic billing eligibility, production profile, deletion or live connector.

`fetch-demo` downloads the immutable official 1000-row CSV URL/revision, bounded by length, and verifies pinned SHA-256 before atomic local rename. `init-demo` is explicit local administrator provisioning: it accepts only those exact bytes and generates two labelled synthetic tenant assignments: AWS to demo-a; Microsoft/Oracle to demo-b. It enumerates exact provider/account/subaccount/billing-period tuples, not provider-only runtime guesses. Generated identifier-bearing configuration stays ignored. A general trusted `init --config` accepts validated explicit tenant properties and exact assignments; runtime ingest cannot provision or change them. Overlapping/duplicate assignments, unknown tenants, invalid timezone/currency/version/bounds and unsafe actor names reject. No source identifier or data row is committed.

Tenant properties: immutable tenant/workspace UUID, display label, IANA reporting timezone, reporting currency (metadata only, no conversion), allowed source currency set including explicit unknown where approved, retention-days metadata (no deletion implementation), exact source tuples, and local reader actor. Currency admission and tuple ownership are enforced; timezone renders local period labels while UTC timestamps/source timezone remain unchanged; retention metadata is surfaced, not falsely enforced. Source account/customer identity is not tenant identity. Configuration revision/digest and mapping digests pin all releases. Changed configuration is rejected by reinit; future reconfiguration requires an explicit reviewed migration/transition, never remapping existing facts silently.

## Mapping and accuracy

Registry-driven file declared version, provider/service columns, source-null tokens, cost/quantity/price mappings and timestamp fields. Install a 1.0 public-demo exploratory profile plus separately labelled 1.2/1.3 mapping profiles; the new path is evidence/query ingestion, not a second full-conformance validator or expanded billing support. No hardcoded version branch, relabelling or fabricated 1.3 fields. Full original CSV is immutable once; each fact also preserves its own lexical row JSON and original ordinal. Missing numeric values carry lexical missing reason; explicit zero remains zero. Provider/service/charge labels remain source values.

Normalize exact values to Decimal(38,18) after bounded lexical/exponent/coefficient checks, never float or implicit rounding. Reject excess scale/magnitude and nonfinite syntax. At most 10,000 rows/16 MiB for this increment; original full 5.48M-row gzip ingestion is not claimed. Before effects validate every input row, timestamp interval, exact assignment, allowed currency, row width, unique/required headers and bounded fields. Independently bound absolute coefficient totals below 10^38 for every additive measure across the entire batch; per-price coefficient also below10^38. This guarantees Decimal128 SUM and exact Decimal256 CH checking without overflow; unit prices are never aggregated. Controls group provider/service/currency/consumed-unit/pricing-unit with per-measure present/missing and NULL sum when no present value. Source precision and units are retained. Official sample fits observed scales up to15 and magnitude4651.

## Authority and publication

PG config/source scope and immutable batch + tenant release/control metadata are authoritative. Stable publication identity is installation/workspace/source, independent of configuration/mapping revision. Unique source revision (positive integer local fixture revision, not invented provider correction order) with exact raw/profile digest: identical authorized replay returns existing outcome; changed bytes/profile conflict. Equal source rows remain separate occurrences by ordinal. Composite tenant/publication references prevent cross-tenant release attachment.

Provisioning uses admin credentials only; runtime importer, approver and per-tenant readers are nonowner/NOSUPERUSER/NOBYPASS roles with validated effective grants/memberships/ownership. PG forced RLS binds tenant reader role to immutable tenant ID without caller-selected tenant GUC. Shared source/config/batch original metadata is coordinator-only; readers see only their tenant properties and tenant-specific release controls. CH has separate scoped reader users and locked settings with effective privilege/policy checks. Explicit tenant + exact PG-selected release filters precede any aggregation; direct unrestricted SELECT under a reader role cannot cross tenants. Readers never receive shared original keys/URLs or other tenant controls.

Preflight full file before reservation; source scope lock serializes ingest/config/current checks. Commit pending reservation before conditional-create original and CH inserts; partial/unknown effects leave pending/unknown reservation that blocks source reuse. No expiry/takeover/cleanup/delete. Recheck current config under lock before every effect; pin exact manifests and source tuple coverage. Verify source counts/ordinal row digests and exact controls against CH tenant slices before verified state. Distinct local approver confirms exact manifest digest and current configuration, then atomically seals batch and swaps all tenant publication pointers with predecessor CAS and append-only decision in one PG transaction. No partially published tenant set. Query reads current sealed pointer and current tenant active policy under PG transaction/scope lock, using tenant CH role; unresolved source operation blocks query, including unchanged former pointer. No shared original export in this increment.
