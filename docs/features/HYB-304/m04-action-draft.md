# Proposed correction and validation

Retain one memory-only frozen action/target/reason under the existing recovery lease, separate from submitted immutable command intents. Permit only suspend, reinstate, retire and revoke, canonical bounded IDs and effective UTF8/rationale/escaped-body bounds. Same action and target may edit; a different action or target cannot replace it silently. Show the retained localized action and canonical target with an explanation, explicit identity-safe discard and Cancel, which closes the current action while preserving the prior draft. Operators may reopen its original target/action. Closing a matching form also preserves its draft; no automatic navigation or submission follows restoration. Existing initial not-stored rationale is only copied on an explicit edit and cannot overwrite a retained draft.

First submissions recheck current eligibility and current byte limits and capture current revision. Once a submitted intent owns the values, clear only the captured draft by object identity/action/target; a refusal that leaves no intent retains editable values. Unknown retries retain the existing original envelope/replay contract. A late completion cannot clear a replacement. Same-lease canonical refresh and view/locale remount retain values; client/user/workspace/CSRF replacement, authentication loss and disposal clear them and fence old callbacks. Unload is guarded while necessary. No password, secret, pickup reference, browser storage or arbitrary population is added.

Validation will pin the actual fail-before refresh, same-scope remount, incompatible action/target explicit discard, fresh eligibility/limits, unchanged frozen replay and authoritative scope cleanup. Pure model tests cover copy/freeze, bounded admission, stale clearing and invalidated access. Run affected Console tests/typecheck/build and mounted browser/provider checks, then scoped independent source and terminology/render re-review. This plan alone claims neither implementation PASS nor full M04 readiness; required package100% coverage and other documented final gates remain open. Existing owner authorization covers eventual reviewed PR251 merge/read-back.


Independent design review returned PASS before production edits. The reviewer identified that commandIntents retains definitive refusals as refused: entry existence alone cannot justify clearing an unsent draft. Preserve its exact captured identity for refused outcomes; matching unknown intent takes precedence over an incompatible unsent draft without clearing it. TextEncoder checks UTF8 byte bounds, not lossless JavaScript-string validation. Implementation and actual-source re-review remain pending.
